# Contributing / المساهمة

Contributions are welcome. Keep changes focused, dependency-light, cross-platform, and safe for user files.

1. Create a branch from `main`.
2. Install development tools: `python -m pip install -e . pytest ruff`.
3. Add or update tests for behavioral changes.
4. Run `ruff check src tests` and `pytest -q`.
5. Update both English and Arabic README sections when user-facing behavior changes.
6. Open a focused pull request explaining the behavior and validation performed.

Do not commit real sensitive files, credentials, private baselines, or generated environments.

المساهمات مرحب بها. اجعل التغييرات محددة، قليلة الاعتماديات، متعددة المنصات وآمنة على ملفات المستخدم. أضف اختبارات لأي تغيير سلوكي، وشغّل Ruff وPytest، وحدّث قسمي README العربي والإنجليزي عند تغيير السلوك الظاهر للمستخدم. لا ترفع أسرارًا أو بيانات خاصة أو خطوط أساس حقيقية حساسة.
